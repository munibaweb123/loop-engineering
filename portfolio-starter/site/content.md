## About
Muniba is a full-stack developer in Karachi who works the overnight shift so clients in other
time zones wake up to finished work. She builds React / Next.js front ends, Python (FastAPI)
back ends, and PostgreSQL data layers, and ships them to Vercel, Render and AWS. The same

## Projects

### PropFlow AI
A production multi-tenant B2B real estate CRM. As team lead of five I designed and built the
whole stack — Next.js front end, FastAPI back end, AWS Aurora PostgreSQL with Prisma — and
deployed it on Vercel and Render. Tenant isolation is real isolation: PostgreSQL row-level
security, role-based access control, and per-tenant data partitioning. On top of the CRM data
model I wired OpenAI Agents SDK workflows to qualify leads and automate follow-up.

### ZARIYA
A fashion and beauty e-commerce platform I co-founded. I own the full stack — product data
modelling, cart and checkout flows, the design system — built on Next.js 16 (App Router),
Tailwind CSS v4, Sanity CMS and Neon PostgreSQL with Prisma 7, and deployed on Vercel.

### Blast Radius Impact Agent
A GitLab Transcend Hackathon project, published to the GitLab AI Catalog. It is a FastAPI +
OpenAI Agents SDK pipeline that ingests merge-request data, walks a code knowledge graph, and
computes the downstream impact of a proposed change before it lands.
