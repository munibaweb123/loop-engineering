# Daily Digest Skill

Gather today's repo activity and post a summary as a comment on the tracking issue.

## Purpose

This skill is used by Routine A (the drafter) in the two-routine gate pattern.
It collects recent activity and drafts a human-readable summary for review.

## Steps

1. **Gather commits from the last 24 hours**
   ```bash
   git log --since="1 day ago" --oneline --no-merges
   ```

2. **Gather open issues**
   ```bash
   gh issue list --state open --limit 10
   ```

3. **Gather open PRs**
   ```bash
   gh pr list --state open --limit 10
   ```

4. **Gather recent PR activity**
   ```bash
   gh pr list --state all --sort created --limit 5
   ```

5. **Format the summary**

   Use this format for the comment:
   ```markdown
   ## 📋 Daily Digest — [date]

   ### Commits
   - [commit message] ([hash])
   - ...

   ### Open Issues
   - #123: [issue title]
   - ...

   ### Open PRs
   - #456: [PR title] — [status]
   - ...

   ### Recent Activity
   - PR #789 opened by @user
   - ...

   ---
   *Generated by Routine A. Review before approving.*
   ```

6. **Post to the tracking issue**
   ```bash
   gh issue comment [ISSUE_NUMBER] --body "[formatted summary]"
   ```

   Replace `[ISSUE_NUMBER]` with the actual tracking issue number.

## Rules

- **Never edit CLAUDE.md, AGENTS.md, or .claude/ files** — these are protected
- **Never push to main** — all changes go to `claude/` branches
- **Never skip verification** — always run `git status` before posting
- **Report only facts** — no opinions, no predictions, no recommendations
- **If a command fails, say so** — never invent data

## Error handling

If any command fails:
1. Log the error in the summary comment
2. Post what you could gather (partial data is better than no data)
3. Include a note: "⚠️ Partial digest — some data unavailable"

## What the human reviews

The human gate (you, the user) will check:
- Is the summary accurate?
- Are all commits listed?
- Are any PRs missing?
- Did the skill avoid editing restricted files?

If the summary looks good, the human fires Routine B to approve it.
If not, the human edits the summary or discards it and tries again.
